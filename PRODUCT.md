# Product
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Approved Snazzy client users editing inventory automation settings from desktop and mobile.

## Product Purpose
A standalone settings website for the LINE inventory import and document publication system. Users find, edit, review and explicitly save a section.

## Capabilities and Constraints
Airtable and Google destinations, allowed LINE groups, import behavior, document captioning and cost estimates. Secrets remain in Worker storage. Changes are revision-checked. Airtable changes require acknowledgement and do not migrate inventory. Local development uses disposable samples. Settings access does not grant recovery access. No deployment is authorized by the redesign.

## Brand Commitments
Latest brief: minimal, compact and not overwhelming on first arrival. Earlier visual directions are superseded. Threads reference is inspiration if appropriate, not a requirement to copy.

## Evidence on Hand
Existing implementation and approved functional specification in docs/superpowers/specs/2026-11-11-settings-console-design.md. Existing Snazzy logo and local Google Sans font.

## Product Principles
- Reveal detail when needed.
- Make saved and unsaved state unambiguous.
- Keep warnings proportional to the action.
- Preserve keyboard and mobile usability.
